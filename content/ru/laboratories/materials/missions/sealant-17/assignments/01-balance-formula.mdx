Автоматический дозатор остановил пробную серию: в одной формуле сумма компонентов оказалась
больше ста процентов. Настоящий образец ещё не готовили — сначала проверь цифровые записи.
Станции нужен маленький калькулятор, который не пропустит несбалансированный состав.
</StationMessage>

## Зачем это станции

Если части одной смеси записаны в процентах, вместе они должны давать `100`. Такая простая
проверка не говорит, что материал безопасен или прочен, но она помогает вовремя заметить ошибку
в данных и не тратить образцы.

## Теория · 10–15 минут

### Переменная — подписанная ячейка

В Python можно сохранить число под понятным именем:

```python
flex_base = 50
reinforcing_fiber = 30
dust_shield = 20
```

Знак `=` здесь означает: «сохрани значение справа под именем слева». Чтобы узнать всю сумму,
складываем переменные:

```python
total = flex_base + reinforcing_fiber + dust_shield
```

### Условие помогает принять решение

```python
if total == 100:
    print("Формула сбалансирована")
else:
    print("Проверь пропорции")
```

Два знака `==` задают вопрос «равны ли значения?». Один знак `=` сохраняет значение.

<ResearcherNote title="Научный факт и модель станции">
Компоненты `flex_base`, `reinforcing_fiber` и `dust_shield` вымышлены. Интерактивная схема ниже
показывает только арифметику пропорций. Настоящие материалы для герметичного обитаемого модуля
проверяют по множеству свойств: механической работе, совместимости, горючести и выделению летучих
веществ. Сумма `100` — необходимая проверка записи, но не доказательство безопасности.
</ResearcherNote>

переменной рядом.
